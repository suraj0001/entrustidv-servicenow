Entrust Identity Verification for ServiceNow

Admin setup guide

Follow these steps to connect Entrust, set up verification, and let agents start identity checks from ServiceNow.

Before you start Get your Entrust Client ID, Client Secret, and Workflow ID. You also need ServiceNow administrator access and access to your Entrust Identity Verification account.

1. Give users access

Assign these roles in ServiceNow under the user record:

UserRoleWhat the role allows
Administratorsx_entru_entrustidv.adminConfigure the connection and verification settings.
Agentsx_entru_entrustidv.agentSee Verify Identity on incident pages and start verification.

2. Configure the Entrust connection

1

Open API Connection

Open the Entrust Identity Verification admin setup page and select API Connection.

2

Choose your region

Select the region used by your Entrust account. ServiceNow fills in the Base URL and Token URL.

3

Enter your credentials

Enter the Client ID and Client Secret from Entrust. Select Test Connection, then select Save after the test succeeds.

3. Set verification settings

  1. Open Verification Settings.
  2. Enter the Entrust Workflow ID that should run for identity checks.
  3. Set how long the verification link should work. The maximum is 48 hours.
  4. Leave Delivery Channel set to Email.
  5. Leave Redirect URL blank, or enter an HTTP or HTTPS page where users should go after verification.
  6. Select Save.

4. Configure the webhook

  1. Open Setup Information and copy the Webhook URL.
  2. In your Entrust Identity Verification account, add this URL as the webhook endpoint.
  3. Copy the webhook token provided by Entrust.
  4. Paste the token into ServiceNow and select Save.

ServiceNow uses the token to check that webhook events came from Entrust.

5. Turn on email

ServiceNow sends verification links by email. Make sure outbound email is enabled:

System Properties > Email Properties > Outbound Email Configuration

Screenshots for reference

6. Test the setup

The API connection test succeeds.
The verification settings are saved.
A test user has the agent role.
Outbound email is enabled.
The webhook is configured in Entrust.
The webhook token is saved in ServiceNow.

Open an incident as an agent and select Verify Identity. Confirm that the user receives the email and that the verification status updates on the record.

Need help? Check the region, credentials, Workflow ID, email settings, and webhook token first. These are the most common setup issues.
