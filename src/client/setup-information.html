Webhook Configuration

Configure this URL as the webhook endpoint in your Entrust Identity Verification account. Entrust will generate a webhook token after the webhook is configured.

Method:POST Content-Type:application/json

Enter the webhook token generated by Entrust. ServiceNow uses this token to verify incoming webhook events.
